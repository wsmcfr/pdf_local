# Local KB UI 重构计划（iOS / 液态玻璃）

日期：2026-10-27
范围：`apps/desktop/src`（React + CSS），不改后端 API、不改数据流。

## 1. 视觉论点

**一句话**：把 Local KB 从「通用后台仪表盘」改造成一块安静、通透的 macOS/iOS 工作台——暖白雾面画布上漂浮半透明玻璃侧栏与内容面板，只用一种 iOS 蓝作为行动色，信息密度不降、视觉噪音大幅减少。

三条原则：

1. **构图优先，组件其次**：侧栏是导航轨，正文是工作区；不再把每个区域都包成带边框的小卡片。
2. **玻璃必须服务于层级**：玻璃只用于「浮在画布上的层」（侧栏、页头、右栏原文、弹层式表单），普通信息用排版和分隔线组织。
3. **单一强调色**：行动/选中/焦点全部用 iOS 蓝，状态色只用于成功/警告/错误，避免多彩竞争。

## 2. 内容计划（每个区域一个职责）

| 区域 | 职责 | 主导视觉 |
| --- | --- | --- |
| 侧栏 | 我在哪、能去哪 | 浮动玻璃导航轨 + 品牌标记 + 蓝色选中胶囊 |
| 页头（粘性） | 这一页是什么、主行动 | 大标题 + 一行说明 + 右侧行动组，滚动时轻微模糊 |
| 资料库 | 浏览与导入资料 | 一张玻璃数据表，表头克制、行悬停高亮 |
| 问答 | 提问与验证答案 | 对话流：用户气泡（蓝）→ 助手玻璃气泡 → 引用列表；右侧原文玻璃栏 |
| 导入进度 | 看进度、控制任务 | 任务卡列表 + 渐变进度条（运行中带微光） |
| 设置 | 调整参数与连接 | iOS 分组表单（1px 分隔线，不用卡片网格）；Provider / 网关为玻璃面板 |
| 开始使用 | 三步完成准备 | 单一玻璃清单，编号圆点 + 细线分隔 |
| 底部状态栏 | 一眼确认服务/Provider/网关 | 细长玻璃条 + 状态胶囊 |

## 3. 交互论点（2–3 个有意义的动效）

1. **页面入场**：切路由时 `.page` 以 0.45s `cubic-bezier(.22,1,.36,1)` 上浮 10px + 淡入，全站一致。
2. **导航/按钮反馈**：导航选中胶囊背景与颜色 0.24s 平滑过渡；主按钮悬停轻微抬升 + 光晕，按下 `scale(.985)`。
3. **状态与进程**：进度条运行中缓慢流光；问答生成中助手气泡带流式光标，文本平滑上屏；状态圆点带柔和光环。
4. 尊重 `prefers-reduced-motion: reduce`，关闭位移与脉冲，只保留颜色变化。

## 4. 设计令牌

| 令牌 | 浅色 | 深色（自动） |
| --- | --- | --- |
| 画布 | `#f5f6fa` + 3 处极淡光晕（蓝/琥珀/紫） | `#0b0d12` + 极淡蓝光 |
| 玻璃面 | `rgba(255,255,255,.66)` | `rgba(28,30,36,.62)` |
| 描边 | `rgba(15,23,42,.08)` | `rgba(255,255,255,.10)` |
| 主文字 | `#10131a` | `#f5f6f8` |
| 次文字 | `#5b616e` | `#a2a8b4` |
| 弱文字 | `#8b909c` | `#7d838f` |
| 强调色 | `#0a84ff`（深 `#0071e3`） | 同色 |
| 成功/警告/错误 | `#34c759` / `#ff9f0a` / `#ff453a` | 同色 |
| 圆角 | 26 / 20 / 14 / 10 | 同 |
| 字体 | 系统 SF/Segoe UI Variable + 微软雅黑；等宽 SF Mono/Consolas | 同 |

阴影只保留两级：`--shadow-panel`（大而淡，制造悬浮感）与 `--shadow-control`（按钮/输入框）。

## 5. 页面级改动

### 5.1 App shell / 侧栏（`App.tsx`, `Sidebar.tsx`, `styles.css`）
- `body::before/::after` 绘制固定环境光晕（不参与滚动），让玻璃有内容可折射。
- 外壳改为 14–16px 内边距 + 268px 侧栏 + 14px 间距；侧栏为 26px 圆角玻璃轨。
- 品牌区：36px 渐变蓝标记（内嵌高光「书页」）+ `Local KB` 字标 + 小号「本地知识库」。
- 导航：14px 圆角行，图标 + 文字；激活态为蓝色浅底 + 蓝色文字，过渡平滑；窄屏收成图标轨。
- 页脚：弱化说明文字，保持「本地知识库 · 离线优先」。

### 5.2 页头
- `.page-header` 变为滚动容器内的粘性玻璃条：负边距铺满、顶部渐变 + 模糊，滚动时内容从下方穿过。
- 标题 27px / 700 / `-0.02em`，说明 13px 次文字；行动组按钮统一高度与间距。

### 5.3 资料库（`Library.tsx`）
- 表格外包 `.table-shell` 玻璃面板（圆角 + 细描边），`overflow:hidden` 保证圆角。
- 表头小号大写弱化；行悬停淡蓝；状态标签为浅色胶囊；数字右对齐，等宽数字。
- 空状态：玻璃面板 + 虚线描边 + 主行动按钮。

### 5.4 问答（`Chat.tsx`, `CitationPanel.tsx`, `PageViewer.tsx`）
- 整页改为「对话工作区」：消息区独立滚动，**输入框固定在页面底部**，页面本身不再滚动。
- 增加用户提问气泡（右对齐、蓝色渐变、白字），助手回答为玻璃气泡；回答按 token 逐个上屏（客户端平滑，即使上游一次返回整段也不会整块闪现），并带闪烁光标。
- 流式期间自动跟随到底部；用户手动上滚后停止自动跟随；生成中提供「停止」按钮。
- 输入区升级为「悬浮玻璃 composer」：透明 textarea、聚焦光晕、右下角主按钮；`Ctrl+Enter` 提示弱化；发送后清空输入、收起原文栏。
- 引用列表改为 iOS 列表行：悬停淡蓝、选中左侧 3px 蓝条；低置信度用琥珀胶囊；点击引用会自动展开原文栏。
- 右栏原文可折叠：页头「收起/展开原文」按钮 + 面板内箭头；提交问题时自动收起，窄窗口下变为带遮罩的右侧抽屉。
- 空状态给出标题、说明与三条示例问题，点击即可填入输入框。

### 5.5 导入进度（`Jobs.tsx`）
- 任务卡改为玻璃卡（20px 圆角），标题 + 状态胶囊一行、进度条 8px 渐变、操作按钮右对齐。
- 运行中进度条加流光动画；空状态与资料库一致。

### 5.6 设置（`Settings.tsx`, `ProviderSettings.tsx`, `GatewaySettings.tsx`）
- 顶层四组参数改为 **iOS 分组表**：`.settings-grid` 是一张玻璃面板，内部 1px 分隔线，`gap:1px` + 描边背景实现发丝线，不再是一堆卡片。
- Provider：左侧为一张玻璃列表（行之间发丝线），右侧为独立玻璃编辑面板。
- 网关：两列玻璃面板 + 跨列「客户端配置片段」；代码块为深色圆角块，复制按钮为小号胶囊。
- 字段：输入框 12px 圆角、内阴影、聚焦蓝色光晕；只读字段灰底；复选框改为 iOS 开关观感（视觉尺寸 18px + 强调色）。

### 5.7 开始使用（`Onboarding.tsx`）
- 三步合并为一张玻璃清单：编号圆点为蓝色浅底，步骤间发丝线，主行动在第三步右对齐。
- 数据目录用等宽胶囊展示；状态行改为圆点 + 文案。

### 5.8 底部状态栏（`StatusBar.tsx`）
- 深色条改为浅色玻璃条（深色模式自动反转），左三组状态做成可悬停胶囊，右侧「刷新」弱化。
- 保留原文案（`本地服务已连接` / `Provider 未配置` / `网关已关闭` 等），测试不受影响。

## 6. 实施步骤

1. 重写 `styles.css`：令牌 → 基础排版 → 外壳/侧栏/页头 → 控件 → 各页面 → 响应式 → 深色模式 → 动效与无障碍。
2. 调整 `Sidebar.tsx`（品牌标记）、`StatusBar.tsx`（状态胶囊）、`Library.tsx`（表格外壳）、`Chat.tsx`（提问气泡）。
3. `Settings.tsx` 数据目录占位文案改为「正在读取…」；`index.html` 换用自有 SVG 图标。
4. 检查每个 JSX 中出现的 class 都有样式（对比清单），不删除任何业务逻辑。
5. 验证：`npm run build`、`npx vitest run`、`cargo check`；启动 `npm run tauri dev` 人工过一遍 5 个页面 + 深色模式 + 1200×800 与窄窗口。

## 7. 风险与约束

- 液态玻璃依赖 `backdrop-filter`：WebView2 支持，但层数不宜多；只在 4 类「浮层」使用，避免性能下降。
- 粘性页头使用 `position: sticky` + 负边距，需确认 `app-main` 是滚动容器且 `page` 不裁剪溢出。
- 不改任何数据请求、路由与后端接口；文案除占位符外保持不变，确保 `App.test.tsx` 通过。
- 不引入新依赖（无 Framer Motion），动效全部 CSS。

## 8. 非目标

- 不新增页面、不新增功能、不做移动端适配（仅窄窗口降级）。
- 不改 Provider/网关的配置逻辑与错误提示语义。
